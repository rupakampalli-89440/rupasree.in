# Kampalli Rupasree — Portfolio

A responsive, dark-first personal portfolio built with plain HTML, CSS, and JavaScript. No build step or package installation is required.

## Run locally

Open `index.html` in a modern browser.

## Add verified portfolio details

The page intentionally leaves out unprovided personal details rather than inventing them.

- Add a real resume file and link it from the hero in `index.html`.
- Update the education card with the institution and graduation year.
- Add project and certificate cards with real descriptions, media, and links.
- Add verified email, LinkedIn, and GitHub details in the contact section.
- Set `CONTACT_EMAIL` near the top of `script.js` to enable the contact form. The form opens a prefilled email in the visitor's email application; it does not send data to a server.
- Replace `rupasree-profile.png` with another portrait to change the hero photo.
- The supplied profile photo is saved as `rupasree-profile.png` and displayed in the home-page hero.

The theme switch, mobile menu, section navigation, reveal animations, and contact form validation work without external libraries. Google Fonts are optional; system fonts remain as fallbacks. Reduced-motion preferences are respected.
